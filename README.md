# GameReact

GameReact è un'applicazione web sviluppata con **React.js** e **Supabase** che permette agli utenti di esplorare, filtrare e interagire con un elenco di giochi. L'app offre funzionalità di ricerca, gestione dei preferiti e chat tra appassionati.

---

## Funzionalità principali

- **Lista giochi**: Visualizza un elenco di giochi prelevati tramite API.
- **Filtri per genere**: Filtra i giochi in base al genere.
- **Ricerca full-text**: Ricerca i giochi per nome o descrizione.
- **Autenticazione utenti**: Registrazione e login tramite Supabase.
- **Lista preferiti**: Gli utenti possono salvare i loro giochi preferiti.
- **Chat nei dettagli del gioco**: Gli utenti possono chattare tra loro nella pagina di dettaglio di ciascun gioco.

---

## Tecnologie utilizzate

- **Frontend**: React.js, React Router
- **Backend / Database**: Supabase (PostgreSQL, autenticazione, storage)
- **API**: Recupero dati giochi tramite API pubbliche
- **Stato globale**: Context API / Redux (a seconda dell’implementazione)
- **Stile**: CSS Modules / Tailwind CSS (a seconda dell’implementazione)
